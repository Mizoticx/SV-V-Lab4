# Task 3 — Identify Events/Conditions

## Autonomous Delivery Robot

| No. | Event / Condition | Description |
|---|---|---|
| E1 | Delivery Request Received | A new delivery request is received by the robot. |
| E2 | Obstacle Detected | The robot detects an obstacle while navigating. |
| E3 | Obstacle Avoided | The robot successfully avoids the obstacle. |
| E4 | Destination Reached | The robot reaches the delivery destination. |
| E5 | Delivery Successful | The package is successfully delivered. |
| E6 | Critical Battery | The robot's battery level becomes critically low. |
| E7 | Warehouse Reached | The robot returns to and reaches the warehouse. |

## Summary

These events and conditions trigger transitions between the robot's different states.
